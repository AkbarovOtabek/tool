🛰️ pentkit

Оркестратор авторизованного пентеста — один интерфейс для recon, Cloudflare-origin, уязвимостей, веб-тестов и отчёта. · 🔀 Прокси (Burp-режим): перехват / Repeater →
⚠️ Запускай только против систем, на тест которых у тебя есть письменное разрешение. Поле «Авторизация» обязательно и попадает в отчёт.

Параметры работы

Tor прячет твой IP (не шифрует до цели — это делает HTTPS). Нужен запущенный сервис tor и proxychains4. Raw-скан (naabu/nmap) автоматически переводится в connect-режим.

Модули сканирования

«Эксплойты» и «msf check» не запускают эксплойты: подтверждают уязвимости (nmap NSE, Metasploit check — неинтрузивно), ищут публичные эксплойты (searchsploit) и готовят .rc для ручного запуска. «Активные SQL-инъекции» (sqlmap/dast) выключены по умолчанию — включай только по согласованию с клиентом, это агрессивный режим.
