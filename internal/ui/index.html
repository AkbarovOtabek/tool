🛰️ pentkit

Оркестратор авторизованного пентеста — recon, поиск origin за Cloudflare, уязвимости, веб-тесты, утечки секретов и отчёт в одном окне.
⚠️ Запускай только против систем, на тест которых у тебя есть письменное разрешение. Поле «Авторизация» обязательно и попадает в отчёт.

Параметры работы

Модули сканирования

«Эксплойты» и «msf check» не запускают эксплойты: подтверждают уязвимости неинтрузивно и готовят .rc для ручного запуска. «Активные SQL-инъекции» агрессивны — включай только по согласованию с клиентом.

2 · Сборка команды Metasploit

check только подтверждает уязвимость. «Эксплуатировать» запускает модуль по-настоящему (по нажатию, не автоматически) — цель проверяется по scope, факт запуска пишется в отчёт. Некоторые эксплойты могут нарушить работу сервиса — сначала жми check.
