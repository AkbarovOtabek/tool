Тонкая настройка модулей
«Эксплойты» и «msf check» не запускают эксплойты: подтверждают уязвимости неинтрузивно и готовят .rc. «Активные SQL-инъекции» агрессивны — только по согласованию.

🧨 Эксплуатация
CVE-находки по версиям сервисов, поиск публичных эксплойтов, msf check и сборка команд Metasploit.
🧨 msf check — неинтрузивное подтверждение уязвимости без эксплуатации. Кнопка «🧨 run» запускает боевой модуль — только с письменного разрешения клиента; цель проверяется по scope, факт запуска пишется в отчёт.

1 · CVE-находки по версиям сервисов (nmap + searchsploit)

Автоматически: nmap определяет версию сервиса на каждом открытом порту → searchsploit ищет публичные эксплойты → ниже список хост:порт с CVE и доступными эксплойтами. Кнопка «↗ В форму» заполняет поля ниже и запускает searchsploit. Кнопка «▶ check» запускает msf check напрямую (нужен msfconsole + явно заданный модуль).
